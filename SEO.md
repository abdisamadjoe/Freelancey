# SEO.md

Rules for website SEO.

- Title tag structure: Business Name: Tagline. ("Daftari: Track Every Shilling in Seconds" not "Home | Daftari")
- Meta description under 160 characters, includes the primary keyword and a reason to click. ("Track expenses and invoices in seconds. Free cash book app for African shop owners.")
- One H1 per page, matching what the page is actually about.
- Headings stay in order: H1, then H2, then H3. Never skip a level.
- Primary keyword appears in the first 100 words of body text.
- URL slugs are short, lowercase, hyphens not underscores. ("/pricing" not "/Pricing_Page")
- Every image has alt text describing what it shows, keyword included only if it fits naturally.
- No keyword stuffing. Write for the reader, keyword placement follows.
- No duplicate title tags, meta descriptions, or H1s across pages.
- Internal links use descriptive anchor text, not "click here." ("See pricing" not "click here")
- Canonical tag set on every page to avoid duplicate content issues.
- Page loads fast and passes Core Web Vitals. No unoptimized images, no blocking scripts.
- Structured data (schema markup) added for products, reviews, FAQs, or business info where relevant.
- Mobile layout checked separately, not assumed to inherit desktop.
- Every page has one clear primary keyword, not several competing ones.
